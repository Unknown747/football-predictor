# Limitations

1. Opening odds TIDAK TERSEDIA di dataset lokal.
2. Semua audit coverage hanya untuk closing odds, bukan opening.
3. Dampak closing-odds bias terhadap performa live BELUM TERVERIFIKASI.
4. Untuk mengukur R2 (closing-odds bias) secara valid, dibutuhkan data
   opening odds dari sumber eksternal (butuh scrape/download terpisah).
5. Tidak ada klaim profitabilitas atau kesiapan live dari audit ini.
