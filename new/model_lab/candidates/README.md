# Kandidat Model

Setiap bundle kandidat harus memuat manifest fitur, parameter, cutoff data, hash input/model, dan alasan pemilihan per pasar.

`EXP06_BLEND_V1_PRIMARY_REFERENCE_ONLY` saat ini menjadi model utama untuk inferensi melalui `predict.py`; Mode B tetap tersedia sebagai pembanding legacy. Bundle EXP-06 berstatus `REFERENCE_ONLY` dan `betting_ready=false`: penempatan sebagai model utama bukan bukti validasi prospektif atau kesiapan taruhan. EXP-07 mencatat hasil prospektif tanpa stake di `new/model_lab/paper/`. Jangan mengubah artefak atau klaim kesiapan tanpa evaluasi dan persetujuan terpisah.
